# V2训练场景库

## 说明

本文件定义训练场景库，用于模拟真实职业场景的能力评估和训练。每个场景聚焦一个特定职业能力维度，支持单独使用或组合成完整的评估流程。

### 扩展方法

如需添加新场景，按以下步骤操作：

1. 在「场景定义」部分新增一个条目，以 `### scenarioKey` 为标题
2. 填写场景基本信息：scenarioKey、场景名称、适用职业（roleKey）、难度（junior/mid/senior）
3. 编写场景描述，包含背景信息和具体任务要求
4. 定义评估标准，每个评分维度取值 0-100
5. 设置建议轮次（1-6 轮），根据场景复杂度确定
