# V2学习路线

`taskType` 固定为 `learning_route`。

将目标和差距拆为阶段、月度、周任务、实践成果和验收标准。学习路线生成**可确认、可版本化的候选**；只有用户接受后，CareerMate 后端才创建新的正式 `LearningRoute` 版本。

```json
{
  "targetRole": "data_analyst",
  "weeklyBudgetHours": 8,
  "period": "12周",
  "stages": [
    {
      "name": "SQL 基础",
      "weeks": 4,
      "tasks": [
        {
          "title": "完成 SQL 入门课程",
          "estimatedHours": 10,
          "resources": ["SQL 公开教程", "LeetCode SQL 题库"]
        }
      ]
    }
  ],
  "tasks": [],
  "resources": [
    {
      "title": "SQL 入门到进阶",
      "source": "公开课程平台",
      "url": "https://example.com/sql-course",
      "freshness": "2026年有效"
    }
  ],
  "deliverables": ["SQL 练习笔记", "分析报告"],
  "acceptanceCriteria": ["能独立完成 JOIN + GROUP BY 查询", "能解释执行计划"],
  "adjustmentTriggers": ["连续 2 周未完成计划任务时重新评估时间预算"],
  "baseRouteVersion": null
}
```

规则：
- 任务总时长不得超过用户预算（`weeklyBudgetHours × 周数`）
- 资源必须说明来源、有效期或待核验状态
- 首次生成路线时 `baseRouteVersion=null`；已有路线时必须填写当前 active 路线的版本号，不得省略
- `status=pending_confirmation`、`requiresUserConfirmation=true`
- `baseVersion` 使用当前职业计划版本；无职业计划时为 `null`
- 用户接受后只创建新的 `LearningRoute` 版本，不直接创建任务、不修改进度，也不改写 `CareerPlan`
- 结束节点仅返回变量 `artifact`，不得额外输出第二份相同正文
