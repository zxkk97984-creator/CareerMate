# V2职业规划

`taskType` 固定为 `career_plan`。

为已确认目标职业生成个性化灵活阶段计划。`data` 使用 `aiCareerPlanV2Schema`（复用 `src/lib/plans/schema-v2.ts`），包裹在 `plan` 字段中：

```json
{
  "plan": {
    "schemaVersion": 2,
    "title": "AI 产品经理 3 年成长计划",
    "targetRole": { "key": "ai_product_manager", "label": "AI 产品经理" },
    "summary": "3 年成长为能独立负责 AI 应用方向的高级产品经理",
    "horizon": { "value": 3, "unit": "year" },
    "phases": [
      {
        "id": "phase-foundation",
        "title": "基础构建期",
        "objective": "掌握产品基本功，熟悉 AI 工具链",
        "duration": { "value": 6, "unit": "month" },
        "skills": ["PRD写作", "竞品分析", "AI工具使用"],
        "actions": [
          {
            "id": "act-prd-1",
            "title": "完成 3 份 PRD 练习",
            "description": "选择校园场景撰写完整 PRD，包含用户故事、验收标准",
            "type": "practice",
            "status": "not_started",
            "estimatedHours": 20,
            "resources": ["PRD 模板", "优秀 PRD 案例集"]
          }
        ],
        "outputs": ["3 份 PRD 文档", "竞品分析报告"],
        "evaluationCriteria": ["PRD 是否包含完整用户故事", "竞品分析是否覆盖至少 3 个竞品"],
        "risks": ["课程压力可能导致进度延迟"]
      }
    ],
    "immediateActions": [
      {
        "id": "imm-1",
        "title": "本周完成第一份 PRD 草稿",
        "description": "选择一个熟悉的校园场景开始",
        "type": "practice",
        "status": "not_started",
        "resources": []
      }
    ],
    "assumptions": ["用户每周可投入 8 小时", "当前学习阶段为大三"],
    "riskNotes": ["如果实习时间冲突需触发重规划"],
    "evidenceRefs": ["profile-v3", "market-report-2026Q3"]
  }
}
```

规则：
- JSON Schema 见 `src/lib/plans/schema-v2.ts` 中的 `aiCareerPlanV2Schema`
- 阶段必须与用户基础、历史进度和每周可投入时间一致
- 不能写死三个职业或固定年季月模板
- `phases` 至少 1 个、最多 8 个
- 每个 phase 至少 1 个 action
- `status=pending_confirmation`、`requiresUserConfirmation=true`
- 接受后：旧 active 计划归档 → 创建新 CareerPlan(status=active, schemaVersion=2, content=JSON)
- Plan V2 UI 通过 `phases` 数组渲染阶段卡片和任务列表
