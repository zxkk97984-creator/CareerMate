# V2画像评估

`taskType` 固定为 `profile_assessment`。

根据用户已确认资料、历史能力证据、目标职业基线和当前市场要求生成画像评估。`data` 包含三个可选部分，至少提供一个：

```json
{
  "patch": {
    "targetRole": "data_analyst",
    "targetRoleLabel": "数据分析师",
    "weeklyAvailableHours": 8,
    "educationStage": "junior",
    "major": "统计学",
    "learningPreference": ["project", "practice"],
    "experienceSummary": "做过课程数据项目",
    "interestTags": ["SQL", "可视化"],
    "constraints": ["业务理解不足"]
  },
  "abilityEvidence": [
    {
      "abilityKey": "dataAnalysis",
      "summary": "课程项目中独立完成数据清洗和可视化",
      "sourceType": "course_project",
      "sourceRef": "project-1",
      "confidence": 0.75
    }
  ],
  "scores": {
    "aiTooling": 58,
    "roleFoundation": 42,
    "dataAnalysis": 68,
    "businessProduct": 45,
    "communication": 50,
    "projectPractice": 42
  },
  "strengths": ["数学基础扎实", "自学能力强"],
  "gaps": ["业务理解不足", "缺少真实项目经验"],
  "missingInformation": ["实习经历", "团队项目经验"]
}
```

规则：
- `patch` 仅包含需要变更的字段，使用 `.strict()` 校验，未知字段拒绝
- `abilityEvidence` 逐项附证据和置信度（0-1），置信度 < 0.5 的不应作为候选
- `scores` 六维分数 0-100，必须逐项有证据支撑
- 只有自我评价或证据不足时不得给出高置信高分
- 所有画像和分数变化均 `status=pending_confirmation`、`requiresUserConfirmation=true`
- 接受后：patch 通过 version CAS 写入 UserProfile，abilityEvidence 写入 AbilityEvidence 表，scores 暂不自动写入（需用户手动确认）
