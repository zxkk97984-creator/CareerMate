# V2简历作品

`taskType` 固定为 `resume_review`。

基于职业证据解析结果、目标职业基线和当前岗位要求，从简历/作品集中提取可验证的能力证据。`data` 输出为 `abilityEvidence` 数组：

```json
{
  "abilityEvidence": [
    {
      "abilityKey": "projectPractice",
      "summary": "独立完成电商转化漏斗分析项目，包含完整的数据清洗→建模→可视化→报告流程",
      "sourceType": "resume",
      "sourceRef": "project-ecommerce-analysis",
      "confidence": 0.9
    },
    {
      "abilityKey": "dataAnalysis",
      "summary": "使用 SQL 和 Python 完成 RFM 客户分层分析",
      "sourceType": "portfolio",
      "sourceRef": "portfolio-rfm",
      "confidence": 0.85
    }
  ]
}
```

规则：
- 不得创造公司、项目、数字、奖项或成果——仅从用户提交的材料中提取
- 每条证据必须标注 `sourceType`（resume/portfolio/certificate/project）和 `sourceRef`
- `summary` 引用原文中可验证的具体内容
- `confidence` 0-1，基于材料的直接性和完整性
- 缺少量化结果时提出补充问题，不代写虚假数字
- `status=pending_confirmation`、`requiresUserConfirmation=true`
- 接受后：逐条写入 AbilityEvidence 表（确认状态）
