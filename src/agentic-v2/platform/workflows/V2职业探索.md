# V2职业探索

`taskType` 固定为 `career_exploration`。

比较用户提出的一个或多个职业方向，结合个人画像、成长历史、职业基线与当前市场证据。`data` 以 `options` 数组为核心：

```json
{
  "options": [
    {
      "roleName": "数据分析师",
      "roleKey": "data_analyst",
      "fitScore": 72,
      "summary": "与你的统计背景高度匹配，SQL 基础可快速转化"
    },
    {
      "roleName": "AIGC 内容运营",
      "roleKey": "aigc_operator",
      "fitScore": 58,
      "summary": "内容创作经验有优势，但数据复盘需要加强"
    }
  ],
  "recommendedOrder": ["data_analyst", "aigc_operator"],
  "risks": ["两个方向都在快速变化，6个月后市场可能不同"],
  "validationExperiments": ["完成数据分析师入职测试题", "试运营一个 AIGC 内容账号 2 周"],
  "roleKey": "new_role_key",
  "roleName": "新发现岗位",
  "category": "数据/分析/决策",
  "abilityWeights": { "dataAnalysis": 0.3, "businessProduct": 0.2 },
  "reason": "基于市场研究建议新增此岗位模板"
}
```

规则：
- `options` 至少 1 个、最多 10 个，每个含 `roleName`（必填）
- 已知职业也不得只套模板，未知职业缺少可靠市场研究时返回 `needs_input`
- 建议以可验证实验代替唯一职业断言
- 如需创建岗位模板候选：填充 `roleKey`/`roleName`/`category` 字段，`status=pending_confirmation`
- 接受后：创建 RoleDraft（待管理员审核入库）
