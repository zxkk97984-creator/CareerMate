# V2成长复盘

`taskType` 固定为 `growth_review`。

综合任务完成、学习投入、能力历史、模拟结果、新证据与市场变化，输出对原计划的修正计划候选。`data` 使用与 `career_plan` 相同的 `aiCareerPlanV2Schema`，并增加 `planPatch` 字段：

```json
{
  "plan": {
    "schemaVersion": 2,
    "title": "数据分析师成长计划（修订版）",
    "targetRole": { "key": "data_analyst", "label": "数据分析师" },
    "summary": "基于过去 3 个月的执行情况调整——SQL 进度超前但业务分析需要加强",
    "horizon": { "value": 3, "unit": "year" },
    "phases": [
      {
        "id": "phase-adjusted",
        "title": "业务分析强化期",
        "objective": "补齐业务理解短板，同时继续推进 SQL 进阶",
        "duration": { "value": 3, "unit": "month" },
        "skills": ["业务指标拆解", "SQL进阶"],
        "actions": [
          {
            "id": "act-biz-1",
            "title": "完成 2 个真实业务分析案例",
            "description": "选择电商或内容平台的公开数据集做端到端分析",
            "type": "project",
            "status": "not_started",
            "estimatedHours": 15,
            "resources": ["Kaggle 数据集", "业务分析框架"]
          }
        ],
        "outputs": ["业务分析报告 x2"],
        "evaluationCriteria": ["分析结论是否有数据支撑", "建议是否可落地"],
        "risks": ["公开数据与真实业务场景有差距"]
      }
    ],
    "immediateActions": [],
    "assumptions": ["用户每周可投入时间不变"],
    "riskNotes": ["如果找到实习需再次调整计划"],
    "evidenceRefs": ["progress-2026Q1", "sim-report-s1"]
  },
  "planPatch": {
    "parentPlanId": "original-plan-id"
  }
}
```

规则：
- `plan` 复用 `aiCareerPlanV2Schema`，是修正后的完整计划
- `planPatch.parentPlanId` 指向原 active 计划 ID
- 只返回相对于原计划的修正版本
- 无可靠历史数据时不得声称能力上升或下降
- `status=pending_confirmation`、`requiresUserConfirmation=true`
- 接受后：旧 active 计划归档 → 创建新 CareerPlan（含 parentPlanId 引用）
