# 用户测试计划

## 测试目标

邀请 5–8 名目标用户完成完整任务路径，评估产品可用性和 AI 质量。

## 参与者画像

- 在校学生（大三/大四，考虑职业方向）
- 职场新人（1-3年经验，考虑转行）
- 职业转型者（3+年经验，跨行业转岗）

## 任务流程

### 任务 1：开始聊天（预期 2-3 分钟）

1. 打开 CareerMate，使用演示账号登录
2. 查看聊天首页，识别"新对话"按钮和欢迎语
3. 发起第一条消息："我想了解一下AI产品经理"

**记录：** 完成时间、是否迷路、第一印象

### 任务 2：探索职业（预期 5-8 分钟）

1. 继续对话，追问 2-3 个关于职业的问题
2. 尝试问一个非内置职业（如"用户研究员"）
3. 查看 AI 返回的来源标签

**记录：** 来源理解度（能否区分"已核验"vs"联网调研"vs"AI推断"）

### 任务 3：确认画像（预期 3-5 分钟）

1. 在对话中表达自己的背景信息
2. 收到画像候选后，点击"确认"/"忽略"
3. 展开成长档案查看已确认的信息

**记录：** 画像可信度评分（1-5）、候选机制理解度

### 任务 4：查看计划（预期 3-5 分钟）

1. 请求 AI 制定学习计划
2. 查看计划摘要卡
3. 点击"查看完整计划"进入职业路径页面

**记录：** 计划可执行性评分（1-5）、是否理解"待确认"状态

### 任务 5：完成本周任务（预期 2-3 分钟）

1. 在计划页查看本周行动
2. 标记一个任务为"完成"

**记录：** 任务操作流畅度

## 评测指标

| 指标 | 目标 |
|------|------|
| 任务完成率 | ≥ 85% |
| 平均完成时间 | ≤ 25 分钟 |
| 来源理解度 | ≥ 80% 能正确区分三种来源标签 |
| 画像可信度 | ≥ 4.0/5 |
| 计划可执行性 | ≥ 3.5/5 |
| NPS | ≥ 40 |
