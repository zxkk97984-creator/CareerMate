# CareerMate 浅色主聊天与工作台改版

设计依据：用户选择的第一张静心对话效果图（exec-f0806215-af5d-4ff0-8f77-b08cf9cb59bb.png）。

目标：在现有 Next.js 项目中启用 /chat，全页与侧边助手共享会话及草稿；保留百宝箱 SSE、真实业务 API 与候选确认。统一侧栏、标题、间距及移动端。无需部署或更换后端。

- [ ] 路由认证测试先验证 /chat 不再重定向概览；实现认证后的主聊天。
- [ ] 用可独立测试的会话 store 统一消息、草稿、历史、失败重试，测试双击、旧请求隔离、持久化元数据。
- [ ] 统一主导航/历史，主聊天空状态、消息、输入器和档案；业务页复用同一助手。
- [ ] 以新增独立样式文件统一白/暖灰/蓝色、阅读宽度、响应式；概览行动优先，路径/资源/训练/记忆层级清晰。
- [ ] 执行单元测试、类型检查、源码 lint、构建；独立 Mock 测试数据下浏览器核验聊天与页面、手机视图，不修改用户正式数据。

保留已有登录/引导规则和 API 模式配置。主聊天支持已登录用户直接访问，完成画像的首页入口切至 /chat。动画角色作为可选收起入口，默认不遮挡工作。
